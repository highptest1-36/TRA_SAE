# Project notes (historical)

Working notes written during the experiments (May–June 2026), mostly in Vietnamese. They record run plans, resume instructions, and revision plans for earlier manuscript versions. They are kept for traceability only.

**The numbers in these notes are not the reported results.** Several notes quote accuracies that include the answer-dependent retry loop (for example 53.92% for cfg3) or a "cfg5 / self-consistency" configuration. The valid single-pass results are the ones in the main [README](../../README.md) and in `analysis/results/`.
